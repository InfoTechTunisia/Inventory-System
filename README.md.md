# نظام إدارة المخزون (Inventory Management System)

هذا المشروع عبارة عن أداة برمجية بسيطة وفعالة لإدارة المخزون، تم تطويرها باستخدام لغة C. يهدف المشروع إلى توفير حل عملي لتنظيم المنتجات وتتبعها.

## 🚀 المميزات
* **الإضافة:** إضافة منتجات جديدة مع تحديد الاسم، الكمية، والسعر.
* **العرض:** استعراض جميع المنتجات المخزنة في شكل جدول منظم.
* **البحث:** إمكانية البحث عن أي منتج باستخدام اسمه.
* **الاستمرارية:** حفظ البيانات في ملف نصي (`inventory.txt`) لضمان عدم ضياعها.

## 🛠 التقنيات المستخدمة
* اللغة: **C**
* التعامل مع الملفات: **File I/O**
* هياكل البيانات: **Structs**

## ⚙️ طريقة التشغيل
1. تأكد من تثبيت مترجم GCC على جهازك.
2. قم بتحميل الملفات إلى مجلد محلي.
3. افتح الطرفية (Terminal/CMD) في المجلد واكتب:
   ```bash
   gcc inventory.c -o inventory
   ./inventory
